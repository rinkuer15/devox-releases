Codex (OpenAI)

Connect Devox to OpenAI’s Codex CLI SDK for strong reasoning, built-in web search, and structured JSON output.

Provider ID: codex · Built-in: ✅ · SDK: @openai/codex-sdk

Prerequisites

Section titled “Prerequisites”
  • Devox installed (see Getting Started)
  • Codex CLI installed separately (see below)
  • An OpenAI account with billing enabled

Install the Codex CLI

Section titled “Install the Codex CLI”

Devox does not bundle the Codex CLI. Install it, then authenticate.

macOS alternative:

Windows note: npm install works but is experimental. OpenAI recommends WSL2 for the best experience.

Native binaries (.dmg, .tar.gz, .exe) are published on the Codex releases page. Drop a binary at ~/.devox/vendor/codex/codex (or codex.exe on Windows) and Devox will find it automatically in compiled binary mode.

See OpenAI’s Codex CLI docs for the full install matrix.

Configuration Options

Section titled “Configuration Options”

Configure Codex defaults in .devox/config.yaml:

modelReasoningEffort (config-level default) controls the reasoning budget per request — higher values spend more tokens on reasoning. webSearchMode controls whether Codex can search the web during execution.

Prefer the unified effort field in workflows

modelReasoningEffort here is Codex’s config-level default. In workflow YAML (workflow- or node-level), use the unified effort: field instead — it works the same way across Claude, Codex, Copilot, and Pi. See Workflow Options below and Reasoning Effort.
