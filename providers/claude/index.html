Claude (Anthropic)

Connect Devox to Anthropic’s Claude Code SDK for the best overall coding capability — extended thinking, MCP server support, per-node skills, cost control, and full tool restrictions.

Provider ID: claude · Built-in: ✅ · SDK: @anthropic-ai/claude-agent-sdk

Prerequisites

Section titled “Prerequisites”
  • Devox installed (see Getting Started)
  • Claude Code installed separately (see below)
  • An Anthropic account and one of: Claude Pro/Max subscription, OAuth token, or API key

Install Claude Code

Section titled “Install Claude Code”

Devox does not bundle Claude Code. Install it separately:

Authentication

Section titled “Authentication”

Claude Code supports three authentication modes via CLAUDE_USE_GLOBAL_AUTH:

ModeWhen to useHow
Global authClaude Pro/Max subscribersCLAUDE_USE_GLOBAL_AUTH=true + claude /login
OAuth tokenAPI billing without CLICLAUDE_CODE_OAUTH_TOKEN=sk-ant-oat01-...
API keyPay-per-useCLAUDE_API_KEY=sk-ant-...

Option 1: Global Auth (Recommended for Subscribers)

Section titled “Option 1: Global Auth (Recommended for Subscribers)”

Then run claude /login to authenticate once. Devox uses your stored credentials automatically.

Troubleshooting

Section titled “Troubleshooting”
SymptomLikely causeFix
claude: command not foundBinary not in PATHAdd ~/.local/bin (macOS/Linux) or %USERPROFILE%\.local\bin (Windows) to PATH, or set CLAUDE_BIN_PATH
CLAUDE_BIN_PATH not picked up on WindowsPath uses forward slashesUse double backslashes: C:\\Users\\<name>\\.local\\bin\\claude.cmd
Auth fails with API keyWrong env var nameUse CLAUDE_API_KEY (not ANTHROPIC_API_KEY) for direct API key auth
Test connection times outAuth missing or slowVerify claude --version works standalone, then check your env vars
