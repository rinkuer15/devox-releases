Bundled Agents — AI Specialists Out of the Box

In Chapter 10 you learned how Devox ships quality-gate hook scripts as bundled defaults. Agents follow the same idea but go further: instead of shell scripts, you get specialised AI personas — security reviewers, TDD guides, code simplifiers, and more — that work across every provider.

This chapter explains the core/curated split, how devox doctor auto-deploys core agents, how to deploy curated agents on demand (via CLI or Web UI Catalog tab), and how to create your own.

What Bundled Agents Are

Section titled “What Bundled Agents Are”

A Devox agent is a Markdown file with YAML frontmatter that describes a specialised AI persona. When you ask Claude, Copilot, Codex, or Pi to “ask the security-auditor”, the provider loads that agent’s system prompt and tools configuration before handling your request.

Bundled agents are the agent definitions that ship inside the Devox binary. They cover the full development lifecycle: planning, coding, testing, reviewing, debugging, and releasing.

Section titled “Core vs Curated”

Section titled “Core agents (15) — auto-deployed”

These agents are actively invoked by Devox’s bundled default workflows. devox doctor self-heals by deploying any that are missing and warns when existing files differ from the latest bundled content.

Why the Split?

Section titled “Why the Split?”

Every .md file in ~/.claude/agents/ is injected into Claude’s context window at session start. Shipping all 29 agents by default consumed unnecessary tokens for agents that most workflows never call. The core/curated split keeps auto-deployed context minimal (~50% reduction) while keeping the full catalog available.

Provider Compatibility

Section titled “Provider Compatibility”

All bundled agents work with all providers. The same .md file serves Claude natively and every other provider via Devox’s agent-file-parser.

ProviderDiscovery MethodNotes
Claude~/.claude/agents/ native scanFull frontmatter: tools, mcp-servers, hooks, isolation
Copilotagent-file-parser.ts + native .github/agents/tools + mcp-servers read natively from .agent.md files
Codexagent-file-parser.ts auto-scanSame directories
Piagent-file-parser.ts auto-scanSame directories

Two agents (rulecheck-agent, triage-agent) use Claude-specific frontmatter (isolation, permissionMode, hooks). These fields are silently ignored by other providers — the agents still work, just without the Claude-only capabilities.

Doctor — Self-Healing Core Agents

Section titled “Doctor — Self-Healing Core Agents”

devox doctor now self-heals core agents:

  • Missing core agents → deployed automatically (same as devox agents deploy --core)
  • Stale core agents (content differs from bundled) → warned but NOT overwritten
  • All 15 present and current → green tick

If you’ve customised a core agent file, the stale warning is expected — your changes are preserved until you explicitly run devox agents update <name>.

Deploying Curated Agents

Section titled “Deploying Curated Agents”

Via Web UI

Section titled “Via Web UI”
  1. Open Agents → Catalog in the sidebar
  2. Curated agents are listed under “Curated Agents — deploy on demand”
  3. Click View to preview the agent’s content
  4. Click Deploy to install it to ~/.claude/agents/
  5. Click Undeploy to remove it again

Adding Your Own Agents

Section titled “Adding Your Own Agents”

Via Web UI (recommended)

Section titled “Via Web UI (recommended)”
  1. Open the Agents tab → Global or Project sub-tab
  2. Click New Global Agent or New Project Agent
  3. Fill in Name, Description, and Prompt / Instructions
  4. Choose Save location:
    • .claude/agents/ — portable across Claude + Copilot + Codex + Pi
    • .github/agents/ or ~/.copilot/agents/ — Copilot-native (.agent.md format)
  5. Optionally expand Advanced to configure tool restrictions and MCP servers
  6. Click Save Agent

The exact file path is shown at the bottom of the form before saving. Editing an existing agent pre-populates all fields including tools and mcp-servers, and unknown frontmatter keys are preserved on save.
