Skills

Section titled “Skills”

Devox ships 79 skills bundled in the binary. Skills inject domain knowledge into AI sessions. They are discovered at runtime from .claude/skills/ and .agents/skills/ directories (both project-level and global ~/).

Provider support: Skills load automatically in Claude and Copilot. For Codex and Pi, Devox injects skill content as context when the workflow node’s skills: field is set.

Core vs Curated

Section titled “Core vs Curated”

Skills are split into two categories (defined in packages/cli/src/bundled-skill-categories.json):

  • Core (18 skills) — required by bundled workflows. Automatically deployed globally during devox setup and verified/repaired by devox doctor.
  • Curated (61 skills) — high-quality but not required by any bundled workflow. Install on demand.
